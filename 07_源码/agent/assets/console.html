方位来源有两种：doa=双麦时延差算出来的；touch=摸到哪半边脸（确定信息，不是估计）。
真机实测本机 STEREO 两路逐采样完全相同（是 HAL 把单路复制两份）， 所以 doa 在这台 ROM 上取不到方向，实际生效的一直是 touch。 屏幕朝向固定为横向（面板原生 800×480，原厂 FaceActivity 也声明横向）。

⑪ 对话日志（机器人说了什么 / AI 答了什么）

—
机器人有三条对话通路，这里统一收：网关=机器人 POST 上来由控制台选的大脑回答； 直连=机器人自己的 key 直接问大模型；原厂xxx=用户话透传给原厂再由原厂打回网关； 心跳=没人理它时它自己说的那句。
一句话只会在其中一条上出现 —— 想知道"到底谁答的"，看括号里那行就行。 落盘在 captures/dialog-*.jsonl，控制台清屏只清内存、不动磁盘。

⑬ 原厂接口（直接调 xldbasesdk）

点「探测可用接口」后这里出现原厂灯光按钮
（ADB / 重启 / 关机 不在本页提供 —— 本页在局域网内谁都能打开，这类操作请走 adb）
—
这一区走原厂自己的 API，不是前面那些我们重写的通道：动作序列用 EngineService.baseAction，随机舞用 radomDance(节奏bpm)， 灯光/电源/ADB 用原厂 SystemMethod 静态方法（拿不到才退回广播兜底）。 机器人端 LediAgent 合并的是原厂 v1.5.10 的 dex，该版本被 R8 混淆过， 类名变成了 xldbasesdk.b / xldbasesdk.b.a， 所以「探测可用接口」会告诉你在这台机器上到底哪些能调、哪些只能广播。

⑭ 屏幕投屏（看屏幕 · 点屏幕）

未投屏
点上方「开始投屏」就能看到机器人屏幕；在画面上直接点 / 拖 / 按住，就是点 / 拖 / 长按机器人。
—
画面走机器人自己的 screenrecord 硬件 H.264，浏览器用 WebCodecs 解码。 不是"每帧一张图"的轮询 —— 本机实测截屏压 PNG 单帧要 640ms，那样只有 1.5fps。
★ 帧率取决于画面变不变（screenrecord 只在画面变化时吐帧，这是它省 CPU 的方式， 不是故障）：画面在动时实测 46fps（466 帧/10s，932 kbps）；画面静止时只有 1~6fps。 所以机器人发呆时画面看着"卡住"是正常的，它一动就流畅。
★ screenrecord 自带 170 秒上限，到点会自动重连（日志里会写），这是它的限制、不是故障。
★ 机器人屏保时画面就是屏保本身，也能点。但注意屏保不认"轻点"（防误触，v142 起）： 要把它叫醒，用 按住画面 ≥5 秒、或直接 POST /sleep {"on":false}。
★ 坐标按画面比例换算成机器人屏的像素，所以把浏览器窗口拉多大都不影响落点。
★ 注入开关：POST /console/mirror {"inject":false} 可整个关掉远程点屏。
★ 诚实口径：injectInputEvent 偶发会返回 false（约两成），那种情况下这里如实报 ok:false，不会假装点成功。

⑮ 长期常听 · 多轮思考（v202）

—
★ 「常听」= 不等唤醒词，一直听（v75 就有）。v202 补的是持久化：
  · 开机自动听：勾上后写进 prefs，Service 起来时自动进入常听 —— 以前开关只活在内存里（contRunning 是进程内 static），重启就丢。
  · 常听与唤醒词互斥（只有一路麦）；机器人说话期间暂停识别是设计不是丢帧。
  · 深睡（屏保）会停常听；退出深睡时若勾了"开机自动听"会自动恢复。
★ 「多轮思考」= 回答前允许模型先向本机要信息 / 让机器人先做个动作，再给最终话 （协议见下，最多 6 轮）。关掉就是老的单轮问答。
—
—
★ 模型协议（纯文本，不用 function-calling —— 各家格式不一、嵌套 JSON 太脆）：
每一行要么是 TOOL 工具名 参数（执行后把结果喂回去继续想）， 要么是 FINAL 最终话（就结束）。
可用工具：state / battery / time / faces / motions / volume / face / motion / led / say / stop —— 全是本机白名单能力，不含任何破坏性动作（关机/重启/关ADB/关网关都不在里面）。
★ 失败一律降级不抛：用满轮数还没给 FINAL 就如实回 ok:false + trace，不硬凑半截话。

⑯ 简易 workflow（v203）

★ 说话以后机器人自己决定要哪些数据与功能 → 查本机能力索引 → 一次交出一串步骤执行。
  · 能力索引是自省出来的（动作表 / 表情表现场读），说明书打包在 assets/ledi_caps.txt 随包发布 —— 不依赖设备上的外部文件。

  · 同时只允许一条流程在跑；破坏性 op（关机/重启/关ADB/关网关）被明确拒绝。
