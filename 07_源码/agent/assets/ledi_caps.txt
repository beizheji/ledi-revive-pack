# 乐迪机器人 本机能力说明书（随包发布，v207）
#
# 用途：给"机器人自己找功能"的 workflow 当检索素材。
# 格式：每行一条  名字<TAB>说明
#   · 名字要和代码里的稳定标识一致（动作名 / 表情名 / 能力名）—— 一致就能把说明贴上去；
#     不一致也不会丢，会作为一条 kind=doc 的软能力进索引。
#   · 用 TAB 分隔，不要用冒号（说明里必然有冒号）。
#   · # 开头是注释，检索时忽略。
#
# ★ 只写"这台机器人真的会做"的事。索引里的能力清单是运行期自省出来的
#   （动作表 MotionController.MOTIONS+DANCE、表情表 FaceController.listFaces()、
#    能力权限表 Abilities.SPECS），本文件只负责把"这些能力是什么意思、边界在哪"讲清楚。
#   ⇒ 本文件写错了不会让机器人"假装会"，但会误导检索排序，所以要如实。

# ================ 安全红线（★ 只读不可改）================
# 用户 2026-10-11 定的口径：AI 可完全接管机器人，但**底层设置不许改**——
# wifi / adb / 开关机 一律"可以查询、不能修改"；
# 会导致失联的操作（深睡/冻结/杀进程）与万能到无法审计的 shell 也不给 AI。
# 想查就用 netinfo / adbinfo / btinfo / screen / sysinfo。要改请人来。
wifi	【红线·只读】改 WiFi 开关与配网——AI 不许改。查询用 netinfo
bt	【红线·只读】改蓝牙开关与配对——AI 不许改。查询用 btinfo
adbwifi	【红线·只读】开关无线调试——AI 不许改。查询用 adbinfo
reboot	【红线】重启系统——不执行
shutdown	【红线】关机——不执行
poweroff	【红线】关机——不执行
closeadb	【红线】关闭 adb 通道——不执行
killsystem	【红线】杀系统进程——不执行
uninstall	【红线】卸载应用——不执行
deepsleep	【红线】深睡（冻住原厂）——会失联，只许人工现场做
freeze	【红线】冻结进程——会失联
kill	【红线】杀进程——会失联
shell	【红线】任意 shell 命令——万能到无法审计，不给 AI
wipe	【红线】清除数据/恢复出厂

# ================ 运动控制（会真的产生力矩，请确认周围空间）================
walk	往前走一段（英文动作名，走/前进/走路都检索得到）
run	跑起来
turnLeft	向左转
turnRight	向右转
hug	抱一抱（张开双臂的拥抱动作）
handshake	握手
cheer	欢呼 / 加油（举手庆祝）
comeon	招手让人过来
beckon	招手
liftHands	双手举高
liftLefthand	举起左手
liftRighthand	举起右手
crosshand	抱臂 / 双手交叉
angry	生气的动作
dizzy	转晕了的样子
wake	醒一醒 / 苏醒动作
sledding	滑雪滑行动作
stand	站直
reject	拒绝（摇头/摆手）
trafficCommand	指挥交通的动作
stStand	站立特技动作
dance	跳舞（舞曲统一走 DANCE 表，动作名形如 dance_LxMyRz）
stop	立刻停下当前动作

# ================ 表情（屏幕上的脸）================
faces	可切换的表情列表由 FaceController 现场读取；表情是原厂资产，名字随版本会变
face	切一个表情（配合说话能表达情绪）
emotion	切"情绪"（原厂情绪词汇表内的才认；reset=回到基线情绪）

# ================ 灯光 ================
led	胸口/头顶 LED 灯，可按颜色开关（红 r / 绿 g / 蓝 b / 黄 y / 粉 p / 全 all）
ledstate	灯语状态：机器人在听=蓝灯常亮；机器人在思考=绿灯常亮（思考结束恢复蓝灯）

# ================ 屏幕 ================
screen	屏幕状态（只读）：屏保 / 深睡 / 旋转锁 / 此刻正在显示什么
display	在机器人屏幕上显示一段文字
displayoff	清屏（去掉屏幕上的文字/图片）

# ================ 查询（只读，全部零副作用）================
state	机器人当前状态一句话汇总：电量 / 屏保 / 深睡 / 音量 / 姿态 / 最近触摸 / 是否常听
battery	机器人自己的电量：百分比、是否在充电、电压、温度、健康度
time	当前日期与时间
motions	能做的动作名清单
netinfo	网络（只读）：WiFi 的 SSID、本机 IP、是否联网
adbinfo	无线调试（只读）：5555 是否真的在监听、端口、可用的 scrcpy 命令
btinfo	蓝牙（只读）：是否开启、本机名、连接状态
sensors	传感器汇总：姿态、最近触摸、陀螺仪、头顶键（短按/长按）、被摸次数
sysinfo	系统：App 版本、已运行时长、内存、存储
pose	姿态与"最近一次下发的动作"（★ 舵机角度**可回读**：见 /motorpos 的 raw/ang —— 原厂 ENGSTATUS 广播的 12 位计数 + 按实测拟合换算出的角度；近似值、不许当控制回路。这里报的"最近下发动作"只是下发值，不代表到位）
logs	最近的运行日志尾部（默认 20 行，可给行数）
micinfo	麦克风（只读）：声源定位开关与方位、是否常听
doc	在本说明书与能力索引里检索："机器人会不会做 X"

# ================ 音频 ================
mic	麦克风：能录音、能听人说话（离线词表识别 / 自由识别两档）
tts	机器人自带嗓音，可以不调大模型直接念一段话
say	用机器人自带嗓音念一句话
volume	音量（0..15），可读当前值、可增减

# ================ 有限更改（可逆、不断连）================
live	待机活泼化总开关（唤醒呼应 / 应答兜底表情 / 待机微动 / 待机动作）
idle	待机动作间隔（拍；1 拍≈8s；0=关掉待机动作）
listen	常听（不等唤醒词一直听）开/关
think	语音回复是否走多轮思考
name	给机器人自己改名字
call	它该怎么称呼你
tone	语气档：adult（大人）/ neutral（中性）/ child（小孩）
rotation	屏幕旋转锁：lock（锁横向）/ unlock（放开自动旋转）
wake	主动发起一次语音对话

# ================ 编排（workflow 自己）================
workflow	把一串"读取 + 动作 + 说话"编成一条命令一次执行；每步只允许调用白名单能力
wait	在编排里等若干毫秒
