二、魔改过的原厂包：到底改了什么

拿原厂原样包（xldrbt_v1.5.10.apk，8cfff20c…，95,913,128 B）与真机在跑的魔改版做 逐条目对差——这是判据，不是自述：

844 个条目，仅 11 处不同，831 处逐字节相同。 也就是说：改动是外科手术式的，整个包 99% 仍是原厂原样。
#条目变化含义
1classes.dex字节数完全相同（7,963,084），内容不同 等长字节码补丁：只改指令/常量，不动 DEX 结构 —— 去掉开机登录引导、把对话端点指向本机
2–5com/allresources/*_filter.properties ×4大幅缩小（如 child 57,607→123） 原厂内容过滤词表被置空（脱厂处理），不再走原厂内容服务
6–10res/mipmap-*/ic_launcher.png ×5尺寸变大 换成自己的图标
11META-INF/MANIFEST.MF + 签名块CERT → PLATFORM 用 platform 密钥重签（这颗 ROM 只收平台签名）
没动的地方（同样重要）：AndroidManifest.xml 逐字节相同、 resources.arsc 相同、全部 lib/*.so 相同（含串口 libserial_port.so、百度唤醒/识别、 灵云 TTS）、全部 assets/（唤醒词、动作表、表情表）相同、classes2.dex 相同。

补丁集为改造工程内完成的等长字节码补丁：脱厂（去引导 / 域名重定向 / 端点改指本机）、 去掉"断网联网/扫码绑定"引导界面与文案（5 处等长补丁）、换图标。 多份产物中，真机装的是 -noguide（= 本机版 + 去引导二合一）。

三、AI 控制包：它是什么、能干什么

一个 App 干两件事 com.ledi.agent

既是语音/动作/表情整机唯一的控制通道： 它在自己身上起一个 HTTP 服务（端口 8899），同网任何手机/电脑开浏览器就能控制， 客户端零安装。

它不自带任何 API Key —— 大模型地址与 Key 由使用者运行时填（兼容 OpenAI 协议）。

能力边界是"可查询"的 GET /abilities

三态权限矩阵：read 只读查询 / write 有限更改 / plan 编排 / forbid 安全红线（重启、关机、关 adb、改 WiFi 等一律只读不可改）。 AI 只能在这个边界内动手。

它怎么连硬件 反射复用原厂引擎

不重造轮子：通过合并原厂 dex + 复用原厂 .so，直接驱动原厂的串口/舵机、唤醒引擎、 表情与动作表；因此 95 MB 的原厂包仍是它的"底座"。

对外接口 199 个端点 / 9 个域

cap · voice · motion · sense · media · ui · sdk · sys · probe。 全部清单见开源仓 06_文档/api/endpoints.json。

两个包如何配合

快速自检（连上机器人后）

# 1) 连上（刷过复活 BOOT 后 adb 立即可用）
adb connect <机器人IP>:5555

# 2) 看它现在能干什么（只读，屏保期也能查）
curl http://<机器人IP>:8899/abilities

# 3) 退出屏保（屏保中动作/说话类接口会回 sleeping）
curl -X POST http://<机器人IP>:8899/sleep -d '{"on":false}'

# 4) 说一句
curl -X POST http://<机器人IP>:8899/say -d '{"text":"你好，我复活了"}'

四、怎么把这两个包装上去

# 魔改过的原厂包（改造产物，来自改造工程 dist/）
adb install -r xldrbt_v1.5.10-noguide.apk

# AI 控制包（开源仓内已附脱敏重编的公开版）
adb install -r 03_App/LediAgent.public-v223.apk

两者都需 platform 签名才能装进这颗"只收平台签名"的 ROM。完整步骤见 复活指南.md。

五、说明：哪些地方还"糙"

如实标注（当前版本的不足）：
  • 魔改包只有二进制、没有源码级补丁集随仓：补丁是"等长字节码改写"，脚本散在改造工程里， 尚未整理成一份可独立重放的补丁说明。
  • 两个包的安装顺序与依赖（谁先谁后、覆盖安装会不会丢数据）未在本轮真机复验。
  • AI 控制包真机是 v222、仓内是 v223-public：二者只差一处被清掉的私网 IP， 但没有真机装过 v223-public，属未验证。
  • 魔改包里的原厂内容过滤词表被置空，其行为影响未做全面回归。
  • 本预览页为说明性文档，不是可执行产物；不包含任何密钥与个人数据。
